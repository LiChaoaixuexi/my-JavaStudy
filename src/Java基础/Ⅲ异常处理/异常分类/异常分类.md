# 一、异常分类
## 1.1 异常体系结构
* Throwable (所有异常/错误的父类)
* ├── Error (错误，通常不可恢复)
* │ ├── VirtualMachineError
* │ │ ├── StackOverflowError
* │ │ └── OutOfMemoryError
* │ └── ...
* │
* └── Exception (异常，可处理)
* ├── RuntimeException (运行时异常，非检查型异常)
* │ ├── NullPointerException
* │ ├── IndexOutOfBoundsException
* │ ├── IllegalArgumentException
* │ └── ...
* │
* └── 其他Exception (检查型异常，如IOException、SQLException等)

## 1.2 检查型异常 (Checked Exception)
* 编译时检查，必须处理
* 继承自Exception（但不包括RuntimeException）
* 示例：IOException、SQLException、ClassNotFoundException

## 1.3 非检查型异常 (Unchecked Exception)
* 运行时异常，编译时不强制处理
* 继承自RuntimeException
* 示例：NullPointerException、ArrayIndexOutOfBoundsException、IllegalArgumentException
